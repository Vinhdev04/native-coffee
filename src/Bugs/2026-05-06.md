# Bugs Log — 06/05/2026
**Người thực hiện:** Vinhdev

## Network Error Spam (Axios)
- **Vấn đề:** Ứng dụng liên tục hiện thông báo lỗi "Kết nối máy chủ thất bại" mỗi khi gọi API `/auth/me` ngầm chạy (do máy chủ dev đang bị down hoặc ngắt kết nối với emulator).
- **Nguyên nhân:** File `axiosClient.ts` đang hiển thị `Toast` lỗi chung cho mọi request bị `Promise.reject()`.
- **Giải pháp:** Bỏ qua (không hiển thị) `Toast` lỗi đối với các cuộc gọi background checking (chứa từ khoá `/auth/me`) mà chưa nhận được response (`!error.response`).
- **File sửa:** `src/api/axiosClient.ts`

## Lỗi Metro Bundler "Unable to resolve"
- **Vấn đề:** Lỗi "Unable to resolve '../../components/common/Toast'" hiển thị ở màn hình console của Metro.
- **Giải pháp:** Cache của Metro chưa cập nhật kịp thời, import trong file `MenuScreen.tsx` (`@/components/common/Toast`) đã chính xác. Lỗi tự giải quyết sau khi reload.

## Toast Message Báo Thành Công Dù Lỗi
- **Vấn đề:** Ứng dụng luôn hiện Toast màu xanh lá (success) kể cả khi đổi mật khẩu thất bại (ví dụ: lỗi ACCOUNT005).
- **Nguyên nhân:** Component `Toast` đang mặc định `type="success"`, khi gọi `setToast` ở màn hình `ChangePasswordScreen` không truyền `type`, dẫn tới bị fallback về giao diện success.
- **Giải pháp:** Cập nhật state `toast` để nhận thêm thuộc tính `type: 'success' | 'error' | 'info'` và truyền `type='error'` vào các block `catch` hoặc `else`.

## API Payload Đổi Mật Khẩu (400 Bad Request)
- **Vấn đề:** API ném lỗi "property old_password should not exist... oldPassword must be a string".
- **Nguyên nhân:** Data gửi đi dùng `snake_case` nhưng API backend yêu cầu `camelCase` (`oldPassword`, `newPassword`, `confirmPassword`). Đồng thời độ dài mật khẩu yêu cầu từ 8 ký tự.
- **Giải pháp:** Cập nhật `authService.ts` map đúng tham số camelCase và apply validate 8 ký tự trên UI thông qua Formik + Yup.
