## 2. Xử lý Bugs & Cải tiến Logic
- Khắc phục lỗi hiển thị Toast Message chồng chéo trên màn hình khi gọi ngầm `GET /auth/me`. Chặn việc `Toast.show` nếu đó là network timeout/down của call auth/me nền.
- Xác định nguyên do Metro Bundler cảnh báo "Unable to resolve": Do cache Metro chưa xoá kịp sau khi di chuyển các components (đã tự giải quyết).
- **Đồng bộ Logic Thực Đơn (MenuScreen)**: Áp dụng logic `SectionList`, `onViewableItemsChanged`, và component `HighlightText` từ Trang Chủ sang màn hình Thực Đơn, giúp đồng bộ trải nghiệm khi cuộn và highlight toàn bộ block sản phẩm tìm kiếm thay vì chỉ text.
- **Formik & Yup Validation**: Chuyển đổi form Đổi Mật Khẩu sang sử dụng `Formik` và `Yup` để handle validation realtime.
- **Sửa lỗi Toast Đổi Mật Khẩu**: Fix lỗi Toast trả về UI màu xanh (Success) dù đổi thất bại. Cập nhật type `error` cho các lỗi API. Sửa lỗi format payload gửi đi (`snake_case` -> `camelCase`).

## 3. Kiến trúc & Hiệu suất
- Việc dùng `SectionList` thay cho `FlatList` mang lại khả năng quản lý layout phức tạp tốt hơn, đặc biệt khi cần tracking item index với `onViewableItemsChanged`.
- Component `HighlightText` tự custom qua Regex là giải pháp gọn nhẹ không cần dùng thêm thư viện bên thứ 3.
- Toàn bộ thiết kế mới tuân thủ triệt để bảng màu `COLORS` và typography `FONTS` hiện tại, đảm bảo tính nhất quán (Consistency) xuyên suốt hệ thống UI của app.

## 4. Góp ý / Kế hoạch kế tiếp
- Hiện tại logic API Đổi mật khẩu chỉ gửi ID và `new_password`. Nếu API Backend yêu cầu gửi cả `old_password` thì cần cập nhật payload trong `handleChangePassword` của màn `ChangePasswordScreen`.
- Có thể áp dụng Skeleton Loading cho các màn AccountInfo và HomeScreen khi gọi API đang chờ, thay thế cho `ActivityIndicator` quay vòng, mang lại trải nghiệm premium hơn.
