## Lỗi Metro Bundler Không Thể Phân Giải Asset (Nghẽn Build APK)
- **Vấn đề:** Khi build APK bản Release, tiến trình bị dừng ở tác vụ `:app:createBundleReleaseJsAndAssets` với thông báo lỗi `Unable to resolve module ... splash_bg.png`.
- **Nguyên nhân:** File `src/constants/Config.ts` khai báo require ảnh `@/assets/images/splash_bg.png` và `@/assets/images/coffee_pattern.png` trong `APP_ASSETS`, nhưng thực tế hai tệp ảnh này không có trong thư mục `src/assets/images/`.
- **Giải pháp:** Tạm thời comment out/ẩn các thuộc tính này khỏi `APP_ASSETS` vì chúng chưa được sử dụng ở bất kỳ màn hình nào.
- **File sửa:** [Config.ts](file:///d:/Work/Bill-Chips-App/src/constants/Config.ts)

## Lỗi HTTP 400 (Phản hồi Lỗi Validation / Lỗi 4000 BE) Khi In Hóa Đơn
- **Vấn đề:** Khi bấm in hóa đơn từ danh sách đơn hàng, API lấy chi tiết đơn hàng trả về HTTP 400 khiến máy in không hoạt động.
- **Nguyên nhân:** Tham số ID đơn hàng gửi đi bị gán nhầm thành mã đơn hàng hiển thị `ORD-20260617-006` (alphanumeric) thay vì ID database `277` (numeric) do cú pháp map sai `id: order.orderCode || order.id` trong file danh sách đơn hàng.
- **Giải pháp:**
  - Cập nhật payload in hóa đơn để tách biệt rõ: Sử dụng ID số (`id`/`orderId`) cho các lệnh gọi API và tạo mã QR, đồng thời lưu mã đơn hiển thị (`orderCode`) làm trường dữ liệu hiển thị riêng.
  - Sửa đổi các file hiển thị hóa đơn và dịch vụ in tương ứng để chuyển sang đọc trường `orderCode` mới này khi hiển thị tiêu đề mã đơn.
  - Bổ sung hệ thống log chi tiết lỗi HTTP và lỗi dữ liệu bất thường ở `axiosClient.ts` để tối ưu hóa việc giám sát và chẩn đoán.
