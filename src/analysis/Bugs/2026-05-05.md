## [BUG-PAY-004] TypeError: Cannot read property 'catch' of undefined
- **Mô tả:** `speakPaymentSuccess` được đổi thành hàm `void` (không async) nhưng code vẫn gọi `.catch(console.error)` trên kết quả trả về. Gây crash toàn bộ luồng thanh toán tiền mặt dù API đã thành công.
- **Vị trí:** `src/pages/orders/PaymentScreen.tsx` — 4 vị trí: polling VNPay (line 131), AppState VNPay (line 175), Cash payment (line 232), Manual confirm (line 503)
- **Call Stack:** `handleCashPayment → speakPaymentSuccess().catch → TypeError`
- **Cách xử lý:** Xóa `.catch(console.error)` khỏi tất cả 4 lần gọi `speakPaymentSuccess`.
- **Trạng thái:** ✅ Đã fix

## [BUG-PAY-005] isSuccess false positive — UI thành công khi BE thất bại
- **Mô tả:** Logic `resCode === 0 || data?.isSuccess === true` luôn cho isSuccess=true khi `res_code=0`, kể cả những trường hợp API trả về lỗi wrapper có `res_code=0` nhưng không có `paymentId`.
- **Vị trí:** `src/pages/orders/PaymentScreen.tsx` — hàm `handleCashPayment`, dòng kiểm tra `isSuccess`
- **Cách xử lý:** Đổi điều kiện thành `resCode === 0 && (data?.paymentId != null || data?.isSuccess === true)` — bắt buộc phải có `paymentId` trong response để xác nhận thanh toán thực sự thành công.
- **Trạng thái:** ✅ Đã fix
